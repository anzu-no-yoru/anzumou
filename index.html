📖 あそびかた

ルール

  • 相手を土俵の外へ押し出したら1点。先に3点とった方の勝ち。
  • 時間がたつと、土俵がだんだん小さくなる（赤い線）。

うごかしかた（画面のどこでも）

  1. 自分のキャラのまわりで、矢印がくるくる回っている。向きは選べない。始まりの向きは毎番ばらばら。
  2. 矢印が相手の方を向いた瞬間に「ちょん」とタップ。その向きへ、まっすぐ「ぽよん」と突進する。
  3. 突進のあとは少し休み（矢印がうすい間は押せない）。
  4. ぐっと長押し（0.4秒）で必殺技。キャラのまわりの輪が一周すると出る。たいせんでは1番に1回。「のこった！」から2秒たつと使える。

土俵ぎわの連打合戦「こらえろ！」と うっちゃり

  • あいてがリーチ（あと1点で勝ち）のときだけ、負けそうな方が土俵のはしまで飛ばされると、止まって「こらえろ！ 連打！」になる。1試合に1人1回（名前の下の「🪢 土俵ぎわ」。光っているときが使えるとき）。
  • 押された方は連打でこらえる。押した方は連打で押し込む。下のゲージが左（こらえる）まで行くか、2.5秒たってゲージが真ん中に近ければこらえた。右まで行くと押し出される。
  • こらえきったら「うっちゃり！」：くるっと体を入れかえて、押してきた あいてを土俵ぎわから投げる。たいてい逆転できるけれど、投げた向きによっては あいてが踏みとどまることもある。
  • れんしゅうでは、土俵ぎわは何回でも起きる（押し込む連打の練習に）。
  • キャラの差：おには連打1回が強い。うさぎはスタミナが減りにくい。

キャラ

🐩 あんずふつう。にがてが無い。連打はふつう。
必殺技「わん！」…ほえて、近くの相手をはじき返す
🐰 うさぎすばしこい。矢印が少し速く回り、休みが短い。スタミナが減りにくい。
必殺技「にだんとび」…同じ向きへ2回つづけて跳ぶ
👹 おに重い。矢印がゆっくり。当たると重い。連打1回が強い。
必殺技「かなぼう」…強い突進。当てた相手を遠くへ飛ばす
🦝 たぬき突進が くねっと曲がる（矢印の回る向きへ）。まっすぐ来ないので読まれにくい。
必殺技「ちゃがま」…茶がまに化けて、1秒ずっしり動かない。ぶつかられても飛ばない
🥣 いっすんぼうし小さくて軽い。すばやいけど押されやすい。
必殺技「うちでのこづち」…5秒だけ大きく重くなって突進する

左右の技（えらぶ画面で 必殺技ボタンの 左・右に 置ける・1番に2回）

🦶 ふんばるその場で ピタッと止まる。土俵ぎわで すべって出そうなときに
↺ 逆向き矢印の回る向きを 反対にする。早く ねらえる
👀 よける横へ 小さくステップ。あいての「！」や 突進を かわす
🫲 はたき向かってくる あいてを 横へ いなす（あいては 押された扱いで 横へ すべる）。来ていないときに押すと「すかっ」と空振りして 少し休み
💪 ため押してから2秒の間、つぎの突進が1回だけ強くなる（ピタッと重なる）。必殺技には効かない

土俵

🟫 土の土俵ふつう
❄️ 雪の夜つるつる。止まりにくい。土俵ぎわは雪だまりで少しブレーキがかかる
🏜️ 砂漠砂で足が重い。動きがゆっくりで、すぐ止まる
🌊 海ぬれた砂でつるつる。土俵ぎわは貝がらの帯で、押されていても どの向きにも遅くなる
🌌 宇宙ふわふわゆっくり。いちど動くと なかなか止まらない
🎲 おまかせ毎番ちがう土俵（同じ土俵は続かない）

  • ☀️ はれ … いつもどおり。🌧️ 雨 … 土俵がぬれて すべる（土と砂漠で。雪・海・宇宙は もともと つるつるなので 見た目だけ）。🌬️ 風 … ゆっくり向きを変える風に 少し流される（白い すじが風の向き）。

あそぶ形

  • たいせん…コンピューターと3点先取。コンピューターのつよさは「えらぶ」画面で 🌱よわい・🍙ふつう・🔥つよい から選べる。あいてのキャラは 🎲おまかせ（毎試合かわる）にもできる。
  • 試合は、ねむる あんずが見る むかしばなしの土俵の夢。始まりの夢の入口はタップでとばせる。
  • 🌐 ネットたいせん…「合言葉をつくる」→ 出てきたリンクを送る。友だちは リンクを タップするだけで入れる。とちゅうで切れても 25秒までは つなぎ直して 続きから。
  • れんしゅう（「☰ もっと」の中）…相手は動かない。必殺技は2.5秒でまた使える。土俵は小さくならない。
  • 見る（「☰ もっと」の中）…コンピューター同士の対戦をながめる。
  • 📲 ホーム画面に置く…「☰ もっと」から。アプリのように 全画面で ひらけて、ネットが無くても遊べる（公開のページだけ）。
  • 🌐 English／日本語…言葉は スマホの言語で 自動で決まる。「☰ もっと」で 切りかえられる。
  • 📅 週の取組…きょうの取組は 月曜から日曜の7日で1組。ボタンの下の 月✅ 火✖ 水● …が この週の結果（●＝きょう まだ）。7日ぜんぶ勝つと「🌙 七日の夢、おしまい」で、結果の画像が金のふちになる。

コツ

  • 土俵のはしでは、まず真ん中へ戻る向きを待ってから押す。
  • 相手が突進したすぐあと（相手の矢印がうすいとき）が攻めどき。
  • 「わん！」は、相手が近く、自分よりはしに近いときに使うと押し出しやすい。
  • 矢印があいての ど真ん中を向いた瞬間に押すと「ピタッ！」。突進が少し強くなる（コンピューターも同じルール）。
  • コンピューターは必殺技の前に、頭の上に赤い「！」が出る。見えたら、よけるか 先に押す。

音・ふるえ

  • 右上の 🔊 で音、📳 でふるえのオン・オフ（別々）。曲は土俵ごとに変わり、土俵がせまくなると少し速くなる。
  • ぶつかる・必殺技・落ちる・勝ち負けのときにスマホが少しふるえる（Android のみ。iPhone のブラウザはふるえない）。うるさければ 📳 でオフに。
  • iPhone は、横の「消音スイッチ」がオンだと音が出ないことがある。

  • 試合が終わると、インスタの縦（4:5）の結果の画像が出る。画像を長押しで保存できる。
  • はじめて遊ぶときだけ、「ちょん」と「長押し」のお手本が出る。
  • 📔 夢日記…取るたびに1行ずつ たまる（たいせん・ものがたり・きょうの取組）。「夢日記をコピー」で最近の30行を送れる。
  • 🏷 二つ名…通算の取り口で「うっちゃりの あんず」「ピタッの名人 あんず」などの 二つ名がつく。
